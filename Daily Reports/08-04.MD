# 08/04

- `<label>` permet de créer un champ de formulaire.
  - Améliore l'accessibilité
  - Permet de cliquer sur le texte du label pour activer le champ lié
  - Formulaire plus clair visuellement
- htmlFor permet de lier le label à l'input pour que cliquer sur le label permette d'activer le champ lié.
- [Lifting state] : Les states sont crées dans le composant React Parent, et transmis à l'enfant via props.
- Transmission d'un key en props : Dans AppointmentList on transmet key={appt.id} à AppointmentItem, mais dans la déclaration d'AppointmentItem, il n'y a que deux props, et key n'apparaît pas. ---> key est spéciale, elle est lue par React, mais pas transmise au component comme une prop classique.
- [Routeur] : Qu'est-ce que j'affiche pour cette URL? Il décide quel composant React afficher.
  - En gros, on paramètre quels compoments afficher en fonction du path. Browser route va donc écouter l'URL du navigateur, et à chaque changement déterminer quoi afficher en fonction de ce qu'on a paramêtré.
