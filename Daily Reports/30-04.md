Learnings :

- CI (Continuous Integration) : Vérifie le projet automatiquement à chaque push sur la branche main. À chaque push sur main, github va :
  - 1 - Récupérer le repo
  - 2 - installer node
  - 3 - installer les dépendances backend
  - 4 - installer les dépendances frontend
  - 5 - builder le frontend
- Si une étape échoue, github marque la CI en rouge.
