Learning :

- `<Routes>` est un conteneur qui check toutes les routes et choisis celle qui correspond à l'URL actuelle.
- `<route element={<>...</>}/>` correspond à ce que React doit afficher. Soit du JSX. <> </> pour encapsuler dans élément est nécessaire parce qu'élément ne peut renvoyer qu'un seul élément. Donc on encapsule tout les élément (les components/form etc...) dans un seul.
- BrowserRouter -> active le routing

  - Routes -> Contient les routes
  - Route -> Associe une URL à un affichage
  - path -> L'URL
  - element -> Ce qu'on affiche
  - <> </> -> Permet de grouper plusieurs éléments.
- <nav< /nav> : Balise HTML qui signifie "Ce bloc contient de la navigation". Important pour les outils (accessibilité malentendants/malvoyants, SEO)
- `<a>` : Balise HTML de navigation classique (Full reload de la page) = Recharge la page et demande au serveur une nouvelle page.
- `<Link to="...">` : Composant React fourni par React Router, remplace `<a>` dans une app React.
- ARIA : Accessible Rich Internet Application --> Norme pour aider les lecteurs d'écran/technologies d'assistances pour l'accessibilité
- aria-label="..." : Label normé pour un élément.


Synoptique :  


- BrowserRouter écoute l’URL

- Routes contient les règles

- Route associe une URL à un composant

- Link change l’URL sans reload

- React affiche le bon composant
